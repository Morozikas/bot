# BYBIT FUTURES ELITE SIGNAL ENGINE

Профессиональная алгоритмическая система анализа рынка криптовалютных фьючерсов Bybit институционального уровня. Написана на языке **Go (Golang)**.

### Что делает программа

Программа непрерывно сканирует все USDT-бессрочные фьючерсы на Bybit, ищет сетапы с высокой вероятностью успеха по методологии Smart Money Concepts (SMC) и отправляет сигналы в Telegram в виде PNG-графика с точными уровнями входа, стоп-лосса и тейк-профита.

**Главный принцип:** система не ищет сделки ради сделок. Если нет сетапа с совпадением всех факторов — сигнал не публикуется.

### Что анализирует

- **Рыночная структура:** BOS (Break of Structure), CHOCH (Change of Character), MSS, свинг-уровни
- **Smart Money Concepts:** Fair Value Gap (FVG), Order Block (OB), Breaker Block, Optimal Trade Entry (OTE)
- **Ликвидность:** Equal Highs/Lows, Buy/Sell Side Liquidity, Sweep ликвидности, Stop Hunt
- **Деривативы:** Open Interest (Build-Up / Unwinding), Funding Rate, L/S Ratio
- **Объём:** Volume Profile, POC, HVN/LVN, VWAP, относительный объём vs исторический средний
- **Корреляции:** тренд BTC и ETH как макро-контекст

### Что публикует

Сигнал отправляется **только** если выполнены все условия: снятие ликвидности (Sweep), подтверждение структуры (CHOCH/BOS), зона входа (OB или FVG), объём выше среднего, OI подтверждает направление, Score ≥ 90, RR ≥ 3:1.

К каждому сигналу — **PNG-график** в стиле TradingView с нанесёнными уровнями.

### Дополнительно

- **Сопровождение позиции:** автоматический перенос SL в безубыток при достижении RR 1:1, уведомления при TP/SL/BE
- **Автоторговля (опционально):** автоматическое размещение ордеров на Bybit для нескольких пользователей с раздельными настройками риска
- **Команда /scan:** по запросу отправляет лучший сетап среди всех монет прямо сейчас

## Настройка Bybit API

### Шаг 1 — Создать API-ключ

1. Войти на [bybit.com](https://www.bybit.com)
2. Аккаунт → **API** → Создать новый ключ
3. Тип ключа: **Системно-сгенерированный**
4. Права:
   - `Чтение` — обязательно (для получения данных)
   - `Торговля фьючерсами` — только если нужна автоторговля
5. IP-привязка: **рекомендуется** указать свой IP (снижает риск компрометации)
6. Скопировать **API Key** и **API Secret** — Secret показывается только один раз

### Шаг 2 — Записать в .env

```env
BYBIT_API_KEY=ваш_ключ
BYBIT_API_SECRET=ваш_секрет
BYBIT_TESTNET=false          # true для тестовой сети
```

> **Без ключей** программа работает в режиме аналитики — использует только публичные эндпоинты Bybit. Сигналы рассчитываются, но ордера не размещаются.

### Защита от банов IP

Bybit ограничивает частоту запросов: **120 req/min на IP**. При превышении — временный бан.

```env
BYBIT_RATE_LIMIT=30           # безопасно: 20-40 req/min
BYBIT_REQUEST_DELAY_MS=500    # 500 мс между запросами
```

При получении ошибки `10006` (IP заблокирован) — подключить прокси:
```env
PROXY_URL=socks5://user:pass@ip:port
```

## Настройка Telegram

### Шаг 1 — Создать бота

1. Открыть [@BotFather](https://t.me/BotFather) в Telegram
2. Отправить `/newbot`
3. Указать имя и username бота
4. Скопировать **токен** вида `1234567890:AAF...`

### Шаг 2 — Получить Chat ID канала/группы

**Вариант A — через @userinfobot:**
1. Добавить [@userinfobot](https://t.me/userinfobot) в группу или канал
2. Отправить любое сообщение — бот ответит с ID чата

**Вариант B — через API:**
```
https://api.telegram.org/bot<TOKEN>/getUpdates
```
Найти `"chat":{"id": -1001234567890}` в ответе.

**Важно:** ID канала/группы начинается с `-100`.

### Шаг 3 — Добавить бота в канал

1. Открыть канал → Настройки → Администраторы
2. Добавить бота как администратора
3. Права: **Публикация сообщений**

### Шаг 4 — Записать в .env

```env
TELEGRAM_BOT_TOKEN=1234567890:AAFxxxxxxxx
TELEGRAM_CHAT_ID=-1001234567890         # ID канала для сигналов
TELEGRAM_EXTRA_CHATS=                   # Доп. каналы через запятую (опционально)
```

### Отправка команд боту

Сигналы отправляются в `TELEGRAM_CHAT_ID` (канал).
Команды (`/scan`, `/status`, `/help`) — только в **личку боту**:

```
1. Найти бота в Telegram по username
2. Открыть личный чат
3. Написать /help
```

```
│   │   ├── map.go              # Карта ликвидности: Buy Side (выше цены) и Sell Side (ниже).
│   │   │                       # Определяет цели для TP и зоны для расстановки SL.
│   │   └── score.go            # Liquidity Score: 30% итогового балла. Наличие свипа +40,

│   │   ├── fvg.go              # Fair Value Gap — три свечи, где средняя создаёт разрыв

│   │   ├── breaker_blocks.go   # Breaker Block — OB, который был пробит ценой и сменил роль:

│   │   │                       # от последнего движения. Если нет OB и FVG — используется

│   │   └── premium_discount.go # Premium / Discount зоны: выше 50% диапазона = дорого

│   │   ├── poc.go              # Point of Control (POC) — уровень с максимальным объёмом.

│   │   ├── hvn.go              # HVN (High Volume Node) — зоны с высоким объёмом.
│   │   │                       # Цель для TP: цена замедляется и разворачивается там.
│   │   │                       # LVN (Low Volume Node) — зоны с низким объёмом, цена
│   │   │                       # проходит их быстро (ускорение движения).
│   │   └── score.go            # Volume Stats: VWAP, MA20 объёма, относительный объём.
│   │                           # Volume < MA20 = штраф −5 к Score (слабое подтверждение).
│   │
│   ├── derivatives/            # ДЕРИВАТИВЫ
│   │   ├── oi.go               # Open Interest — количество открытых контрактов.
│   │   │                       # Long Build-Up: цена↑ + OI↑ = институционал покупает.
│   │   │                       # Short Build-Up: цена↓ + OI↑ = институционал продаёт.
```

## Принцип работы

**Каждые `SCAN_INTERVAL_SEC` секунд:**
```
1. GetTickers("") — 1 вызов для всех 400+ монет
2. Ранжирование по относительному объёму и OI
3. Топ-N монет → загрузка свечей D/4H/1H/15M/5M
4. Для каждой монеты — 16-шаговый конвейер
5. Сигнал найден → Pending Zone
6. Цена вошла в зону + подтверждение свечой → PNG + Telegram
```

---

## 16 шагов конвейера

| # | Проверка | Автосканер | /scan |
|---|---|---|---|
| 1 | Компрессия волатильности | блок | блок |
| 2–3 | Структура рынка 1H + 15M | — | — |
| 4 | Направление BOS/CHOCH | блок | EMA fallback |
| 5–6 | Ликвидность + Sweep | блок | штраф Score |
| 7–8 | FVG + Order Block | — | — |
| 9 | OI Build-Up/Unwinding | штраф −5 | штраф −5 |
| 10 | Объём vs MA20 | штраф −5 | штраф −5 |
| 11 | Корреляции BTC/ETH | ±Score | ±Score |
| 12 | Score ≥ MIN_SCORE_PUBLISH | блок | — |
| 13 | Точка входа (OB→FVG→OTE) | блок | блок |
| 14 | SL ≤ 2.5% от входа | блок | — |
| 15 | RR ≥ MIN_RR | блок | — |
| 16 | Probability ≥ MIN_PROBABILITY | блок | — |

## Команды Telegram

Писать **в личку боту** (не в канал):

| Команда | Действие |
|---|---|
| `/scan` | PNG лучшего сетапа из всех монет (без порогов) |

## Формат сигнала

```
🟢 LONG BTCUSDT  |  INTRADAY

ENTRY:  104 250
STOP:   103 150  ↓-1.05%

TP1:  106 500  ↑+2.15%
TP2:  108 900  ↑+4.45%

RR: 1:3.2  |  Score: 91/100  |  Prob: 88%
Setup: Liquidity Sweep + Bullish OB + CHOCH + OI Expansion
⏰ ~4ч
```

К сигналу прилагается **PNG-график** с OB, FVG, зоной входа, SL и TP.

## Ключевые параметры .env

```env
# Защита от банов Bybit
BYBIT_RATE_LIMIT=30           # req/min (безопасно: 20-40)
BYBIT_REQUEST_DELAY_MS=500    # задержка между запросами в мс
# PROXY_URL=socks5://...      # при IP-банах

# Сканирование
SCAN_INTERVAL_SEC=600         # интервал скана в сек
ANALYSIS_LIMIT=15             # монет для глубокого анализа
WORKER_COUNT=3                # параллельность (1-4)

# Качество
MIN_SCORE_PUBLISH=90
MIN_RR=3.0
MIN_PROBABILITY=85

# Режим
TRADE_MODE=both               # intraday | swing | both
TP_COUNT=2                    # количество тейков
BREAKEVEN_AT_RR=1.0           # SL в BE при RR 1:1
```

## Автоторговля

```env
TRADING_ENABLED=false
```

Поддерживается до 10 пользователей (`USER_1_` ... `USER_10_`).
